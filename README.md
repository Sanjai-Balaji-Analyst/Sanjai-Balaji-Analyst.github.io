# Portfolio site — source

This repo is the source for my portfolio website, hosted via GitHub Pages.

- `index.html` — the site itself (self-contained, no build step)
- `projects/` — the underlying reports and code that the site links out to

Live at: https://sanjai-balaji-analyst.github.io *(once GitHub Pages is enabled on this repo — see below)*

## Enabling GitHub Pages

If the site isn't live yet: go to this repo's **Settings → Pages**, under "Build and deployment" set **Source** to "Deploy from a branch", branch **main**, folder **/ (root)**, then **Save**. GitHub publishes it at the URL above within a minute or two.
